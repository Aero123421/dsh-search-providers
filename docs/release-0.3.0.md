# 0.3.0 更新内容

検索プロバイダー設定の共通ヘッダーに、実行版、正式Releaseの更新確認、明示的な導入操作を追加します。日本語・英語・中国語とDSHのUI部品を使用します。

更新はDSHのplugin managerに委譲し、bundleの有効状態、APIキー、既定検索先、追加機能の選択を維持します。GitHub/tagとtgzの配布経路を維持し、tgzはサイズ制限付きで取得してSHA-256を照合します。

導入失敗、取消、設定による上書き、再起動待ち、実行版確認、接続後の結果不明を区別します。同じ操作IDの導入は再送しません。managerなし・読み取り専用・開発用導入は手動更新先を表示します。

検証したコマンド・対象はPRに記載します。Windows・macOSの実機、Electron版、実APIキーを使う有料検索は今回の検証対象に含めていません。正式なv0.3.0の公開と、その配布物から次のReleaseへの実更新は公開後の検証が必要です。
