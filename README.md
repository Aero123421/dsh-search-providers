# DSH 検索プロバイダー

DeepSeek Harnessで検索先を選ぶプラグインです。Keenable、Nimble、TinyFish、Parallel、Exa、Brave、Perplexityに対応します。

通常の `web_search` はDSHの既存ツールを使います。複数クエリの処理、結果カード、出典、会話履歴、システムプロンプトを維持します。対応版はDSH `0.2.1-alpha.2`です。

## インストール

ビルド済みファイルを含むローカルディレクトリを追加します。

```sh
dsh plugin --profile web add -w ./dsh-search-providers
```

DSHを再起動し、「設定 → 検索プロバイダー」を開きます。

## 使い方

1. プロバイダーの「APIキーを保存」を押します。Keenableはキーなしでも使えます。
2. プロバイダーを有効にし、「通常検索に使う」を押します。
3. 必要な追加機能を「使う機能を選ぶ」で有効にします。

通常検索は選んだ1社だけを使います。他社への自動切り替えはありません。追加機能は通常検索とは別に提供元を選べます。同じ機能で別の提供元を選ぶと、以前の選択を置き換えます。

プロバイダーを無効にしても、APIキーと機能の選択は残ります。無効にしたプロバイダーの追加ツールはエージェントから外れます。既定のプロバイダーを無効にすると、通常検索はエラーになります。

APIキーはDSHの資格情報ストアに保存します。画面にキーの値は返しません。保存済みのキーがない場合は各社の環境変数を使います。

## 追加機能

| 機能 | 提供元 |
| --- | --- |
| ニュース検索 | Nimble、TinyFish、Exa、Brave |
| 論文検索 | Nimble、TinyFish、Exa |
| コード検索 | Nimble |
| 人物検索 | Exa、Perplexity |
| 企業検索 | Exa |
| 画像・動画検索 | Brave |
| ページ本文取得 | Keenable、Nimble、TinyFish、Parallel、Exa |
| サイト内のページ一覧 | Nimble |

追加機能は最初はすべて無効です。有効な機能だけエージェントにツールとして渡します。ニュース・論文検索も追加ツールとして登録し、標準 `web_search` の入力を変えません。`web_fetch` もDSH標準のままです。

本文取得は独立した `extract_web_page` です。外部APIが対象ページのHTTPステータスを返さない場合があるため、標準 `web_fetch` の代わりにはしません。外部の調査エージェント、ブラウザ操作、クロール、定期監視は含めていません。

[API仕様と対応範囲](docs/providers.md) · [開発と検証](docs/development.md)

## 元の検索先に戻す

「DSH標準 → 通常検索に使う」で、このプラグインで変更する前の検索先に戻します。アンインストールする場合は先に戻してください。

```sh
dsh plugin --profile web remove -w @aero123421/dsh-search-providers
```

アンインストール後はDSHを再起動します。保存済みのキーは自動削除しません。

## 検証

LinuxのDSH Webで、インストール、検索先の切り替え、設定保存、既存検索処理、出典表示、履歴用情報、プラグインの解除を確認しています。UIは日本語・英語・中国語、ライト／ダーク、狭い画面で確認しています。

Keenableはキーなしの実検索で確認しています。他の6社はモック応答での検証です。実APIキー、検索品質の比較、Windows・macOSの実機、Electron版は未検証です。
